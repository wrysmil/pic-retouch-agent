# 需求文档：营销图、投放尺寸与物料打包导出

> 项目：pic-retouch-agent（AI 修图智能体）
> 主题：从当前画布一键出营销图与多投放尺寸，并把素材打包成 ZIP 交付
> 日期：2026-10-12
> 前置：拆层后的分层与选区操作（图层与选区按层拆步）

## 1. 背景与目标

到这一步，Agent 已能在画布内改图、拆层、按层操作，但产物始终停在「一张编辑后的画布」。电商场景真正的交付不是一张图，而是一整套物料：详情页要白底主图，投放位要场景氛围图和模特上身，大促要海报，同一张图还要出 1:1、4:5、9:16 三个投放尺寸，最后把这些图连同清单一起发给运营。

在此之前的三个缺口：

1. **营销图没有专门入口**。用户想「出一张商品主图」只能反复调生成工具并手打提示词，四类图各有一套写法，重复且不稳定。
2. **改尺寸只能裁切**。`crop_canvas` 会切掉主体，出投放尺寸需要的是「完整放入画幅、留白补齐」，不是裁切。
3. **产出的图散在图片墙，交付要手动存**。没有把营销图和投放尺寸连同当前画布一次性打包下载的能力。

本里程碑补齐从「一张画布」到「一套可交付物料」的链路：营销图与投放尺寸两类工具，加一个打包导出接口和独立的导出物料页面。

## 2. 用户与场景

| 角色 | 场景 |
|---|---|
| 电商运营 | 在编辑器点「导出」进入导出物料页，选一个会话，四类营销图各点一次生成 |
| 电商运营 | 输入海报文案「新品首发 限时 8 折」，生成的促销海报带上这句文案 |
| 电商运营 | 点「生成 1:1 / 4:5 / 9:16」一次出三个投放尺寸，主体不被裁切 |
| 电商运营 | 在打包区勾选要交付的图，点「打包 N 张」下载一个含 manifest.json 的 ZIP |
| 电商运营 | 只想出单个尺寸时，点某个比例按钮单独生成 |
| 创作者 | 在对话里说「出一张商品主图」，Agent 直接调营销图工具，结果进图片墙不改画布 |
| 创作者 | 在对话里说「出投放物料」，Agent 用投放尺寸工具而非裁切 |

## 3. 功能需求

### 3.1 营销图工具 F1

- **F1.1** 一个工具产出四类营销图，`kind` 取 `product`（白底主图）/ `scene`（场景氛围）/ `model`（模特上身）/ `poster`（促销海报）之一，每类内置一段固定提示词。
- **F1.2** 可选 `caption`（最长 200 字）追加为「文案：…」，用于海报标题或补充要求；留空不追加。
- **F1.3** 支持 `count`（1–4）与 `ratio`（默认 1:1）；生成后统一缩放到目标比例尺寸再入库。
- **F1.4** 结果只作为营销素材进图片墙，**不改动当前画布、不增加修订号**。
- **F1.5** 属像素类排队工具，带阶段与进度回调。

### 3.2 投放尺寸工具 F2

- **F2.1** 把当前画布完整放入若干投放比例，采用留白补齐（居中），**不裁切主体、不改动画面像素**。
- **F2.2** `ratios` 默认一次出 `1:1`、`4:5`、`9:16`；可传单元素只出一个；重复比例去重后按给出顺序处理。
- **F2.3** 结果作为导出素材进图片墙，同样**不改画布、不增加修订号**。
- **F2.4** 因只做本地留白缩放，当场完成、不入队。

### 3.3 对话触发 F3

- **F3.1** 系统提示词补充：出营销图/主图/场景图/模特图/海报用营销图工具，`kind` 对应四类；改尺寸/出投放物料用投放尺寸工具，不要用裁切。
- **F3.2** 单步营销图指令直接进入执行（与既有单步计划一致），步骤卡片显示中文工具名。

### 3.4 打包导出接口 F4

- **F4.1** 提供按会话打包的接口：入参可选一组 `asset_ids`；为空时默认收集营销图与投放尺寸两类素材。
- **F4.2** 未指定且无可打包素材时，退化为「当前画布合成图」单张打包。
- **F4.3** 显式传入的 `asset_ids` 必须属于该会话，否则返回 422。
- **F4.4** 当前图对应的 `asset_id` 以合成画布为准打包，`kind` 记为 `canvas`。
- **F4.5** 返回 `application/zip`，文件名带会话标题与日期，用 RFC 5987 编码支持中文；ZIP 内每张图一条 `images/序号-类别-比例.ext`，并附 `manifest.json` 记录标题、会话、时间与每项的文件名、类别、比例、尺寸、素材 id。
- **F4.6** 越权访问他人会话统一 404。

### 3.5 导出物料页面 F5

- **F5.1** 新增独立路由 `/marketing`（会话选择）与 `/marketing/:sessionId`（工作区），顶部导航加入「导出」入口。
- **F5.2** 无会话参数时列出素材库供选择或新建会话；有会话参数时显示当前画布缩略、标题、画布尺寸与会话切换下拉。
- **F5.3** 四类营销图各一张卡片，共享一个文案输入框；工具处理期间禁用并显示阶段与进度。
- **F5.4** 投放尺寸区提供「一次出三个」与「单个比例」两类按钮。
- **F5.5** 打包区默认选中营销图与投放尺寸（无则当前画布），支持全选/取消、逐项勾选与打包下载，展示每张图的类别标签与比例标签。
- **F5.6** 编辑器工具栏新增「导出」链接，直达当前会话的导出物料页。

## 4. 非功能需求

- **NFR1** 营销图与投放尺寸只读当前画布、只写图片墙，绝不改动会话文档或修订号。
- **NFR2** 打包不落新表、不存中间文件，ZIP 在内存生成后即回。
- **NFR3** 投放尺寸不产生裁切，保持主体完整是本工具存在的核心理由，禁止用裁切工具替代。
- **NFR4** 文件名与清单需安全化：非法字符剔除、标题截断、中文用百分号编码。

## 5. 验收标准

- [ ] 只读校验：营销图与投放尺寸执行后 `current_asset_id` 不变、`revision` 仍为 1。
- [ ] `generate_marketing`（kind=product）产出 1 张 1080×1080 的 marketing 素材。
- [ ] `prepare_delivery_sizes` 默认产出 1080×1080、1080×1350、1080×1920 三张 export 素材。
- [ ] 空会话调用导出接口返回含当前画布合成的 ZIP，manifest 标题与文件名一致、仅 1 个 canvas 项。
- [ ] 出完三个投放尺寸后打包，ZIP 恰含 manifest.json 与三张图，比例集合为 {1:1,4:5,9:16}，素材 id 与图片墙 export 项一致。
- [ ] 传入他会话的 `current_asset_id` 打包返回 422；他人会话打包返回 404。
- [ ] 对话中「出一张商品主图」被规划为单步 `generate_marketing`，卡片标签为「营销图」，轮次进入 running。

## 6. 范围与非范围

**在范围内**：营销图与投放尺寸两类工具、比例反查与留白缩放、按会话打包导出接口、导出物料页面与编辑器入口。

**不在范围内**：营销模板库与历史复用、批量任务（另见批量里程碑）、把 ZIP 落对象存储给外链、在页面内预览/编辑 manifest。

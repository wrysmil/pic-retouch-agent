# 需求文档：拆层文字与文案编辑

> 项目：pic-retouch-agent（AI 修图智能体）
> 主题：勾选拆文字后从主体/背景抠掉原像素字，文字层可改文案、字号与颜色；导出合成文字，成层仍只抠图像以免重影
> 日期：2026-10-12
> 前置：拆层后的分层与选区操作

## 1. 背景与目标

拆层默认只出「背景 + 主体」两层，文字留在像素里。用户明确要求拆文字时（`include_text`），系统会识别出文字框、额外生成矢量文字层，但那时原图上的像素字还留在主体和背景上——矢量字叠在像素字正上方，边缘一圈就露出旧字的残影，改文案时旧字也不跟着变。文字层生成之后也一直是个「哑图层」：能显隐、能挪位，但内容、字号、颜色都定死在拆层那一刻，想改一个字只能重拆。

本里程碑补齐这条链路，让「拆出文字」真正可用：

1. **抠掉原像素字**。拆文字时把识别到的文字框从主体层挖空、在背景层用周围色填上，矢量字取代像素字，不再重影。
2. **文字层可编辑**。新增 `set_layer_text`：改文案，可选改字号与颜色；不点名图层时默认改最上层可见文字，点名到图像层直接拒绝。
3. **画布上直接改字**。选中态双击文字层浮出输入框，回车/失焦写入、Esc 取消，改的过程中原 Konva 文本隐藏，避免旧字和新输入叠着看。
4. **面板里改文案/字号/颜色**。图层面板给文字层加「文字」表单：文本框 + 字号滑杆 + 取色器，输入即时预览、失焦或 ⌘Enter 才落一次编辑历史。
5. **导出合成文字**。拍平（`flatten`）时按矢量把文字层画进图，用系统 CJK 字体，容器里装上文泉微米黑，保证中文导出不断字。
6. **成层只抠图像**。「把选中的物体独立成层」仍保留矢量字，拍平喂模型时跳过文字层（`include_text=False`），免得把字当像素抠进物体层。

## 2. 用户与场景

| 角色 | 场景 |
|---|---|
| 创作者 | 拆层时勾选拆文字，主体和背景上看不到原来的像素字，只有干净的矢量文字层 |
| 创作者 | 画布上双击文字层，直接改文案，回车即写回，⌘Z 能撤销 |
| 创作者 | 在图层面板把标语字号调大、改成品牌色，边拖边看预览，松手才落历史 |
| 创作者 | 说「把主标题改成『双十一大促』」，智能体点名该文字层调用 `set_layer_text` |
| 创作者 | 导出或合成时，文字层作为清晰矢量字进最终图，中文不缺字 |
| 创作者 | 「把这个物体单独成层」时，画布上的标语文字仍留在原地，不被抠进物体层 |

## 3. 功能需求

### 3.1 拆文字时抠掉原像素字 F1

- **F1.1** `split_layers` 传 `include_text` 且识别到文字框时，除生成矢量文字层外，还要**从主体层挖空这些文字框**（挖成透明），**背景层用 inpaint 填上周围色**。
- **F1.2** 文字框遮罩按框略外扩（默认 3 像素），避免边缘残留一圈旧字描边。
- **F1.3** 没识别到文字（`include_text` 但框为空）时主体、背景保持原样，不做无谓的挖空与填充。

### 3.2 文字层可编辑 F2

- **F2.1** 新增画布工具 `set_layer_text`（标签「改文字」）：入参 `text`（必填，最长 500）、可选 `font_size`（8–400）、可选 `fill`（`#rgb` 或 `#rrggbb`），不传的字段保持原值。
- **F2.2** 不点名图层时，作用于**最上层可见的文字图层**；一张文字层都没有时报「没有可编辑的文字图层」。
- **F2.3** 点名到图像图层时报可展示的中文错误「只能改文字图层的文案」，不改文档。
- **F2.4** 改文案时图层名跟着变（取文案前 12 字），保持面板标题与内容一致。

### 3.3 画布上双击改文案 F3

- **F3.1** 交互态下双击文字层进入编辑，浮出与该文字位置、缩放、旋转对齐的输入框。
- **F3.2** 编辑期间原 Konva 文本隐藏、缩放手柄收起，避免旧字与输入框重叠、误拖。
- **F3.3** 回车或失焦提交（内容变化才调用 `set_layer_text`），Esc 取消；切换会话或进入裁剪/对比/选区模式时自动退出编辑。

### 3.4 图层面板文字表单 F4

- **F4.1** 选中文字层时，图层面板出现「文字」区：多行文本框、字号滑杆（8–120）、颜色取色器。
- **F4.2** 输入即时写画布预览（`setLayerPreview` 按同 id 合并），失焦、⌘/Ctrl+Enter 或改色时才提交一次，内容/字号/颜色与当前层无差异时不提交。
- **F4.3** 提交走 `set_layer_text` 并点名当前文字层，与其他编辑一样进编辑历史、可撤销。

### 3.5 导出与成层对文字的处理 F5

- **F5.1** `flatten` 默认把可见文字层按矢量合成进图：居中绘制、按 `fill` 上色、按 `font_size` 取字号，沿用图层的位置/缩放/旋转/透明度变换；空文案不绘制。
- **F5.2** 容器镜像安装中文字体（文泉微米黑），本机按 macOS/系统 CJK 字体路径回退，导出中文不断字。
- **F5.3** 颜色容错：三位十六进制补成六位，非法值回退默认墨色 `#141414`。
- **F5.4** `promote_object_to_layer`（成层）拍平喂模型时**跳过文字层**（`include_text=False`），矢量字不被当成像素抠进物体层。

## 4. 非功能需求

- **NFR1** 不新增数据库表与列；文案、字号、颜色复用图层文档既有字段。
- **NFR2** `include_text` 默认 `True`，未拆文字的旧场景与不传该参的调用行为不变。
- **NFR3** 文字编辑与像素编辑共用同一套画布预览与编辑历史机制，撤销/重做语义一致。
- **NFR4** 前端预览只改内存态，不落库；只有提交（失焦/回车/改色）才产生一次编辑历史，避免逐字符写历史。

## 5. 验收标准

- [ ] `split_layers` + `include_text`：主体层文字框处 alpha 归零，背景层对应区域被填成周围色，不再有像素字。
- [ ] 无文字框时 `remove_text` 原样返回主体与背景。
- [ ] `set_layer_text` 不传 `layer_id` 时改到最上层可见文字层；传图像层 id 报错「只能改文字图层的文案」。
- [ ] 改文案后图层名同步为文案前缀；改 `font_size`/`fill` 生效，未传的字段保持原值。
- [ ] 面板输入文字即时预览、失焦提交；与当前层等值时不提交。
- [ ] 画布双击文字层进入编辑、Esc 退出，提交仅在内容变化时触发 `set_layer_text`。
- [ ] `flatten` 含可见文字层时导出图内有该文字；`include_text=False` 时导出无文字。
- [ ] 空文案的文字层不绘制图层名。

## 6. 范围与非范围

**在范围内**：拆文字时抠原像素字（主体挖空 + 背景填充）、文字遮罩外扩、`set_layer_text` 工具与默认目标解析、画布双击行内编辑、图层面板文字表单与预览合并、导出按矢量合成文字、成层跳过文字。

**不在范围内**：富文本（粗体/斜体/多色）、逐字排版与自动换行算法、字体选择器（仅系统 CJK 回退）、把文字遮罩作为可编辑选区暴露、OCR 之外的文字识别。

## 7. 后续依赖

- 「编辑页交互与进度统一」的 `setLayerPreview` 合并语义被本里程碑的文字预览复用。
- 后续若要支持多字体或富文本，绘制入口已收敛在 `render._composite_text`，可在此基础上扩展。

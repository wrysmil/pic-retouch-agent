# 需求文档：拆层后的分层与选区操作

> 项目：pic-retouch-agent（AI 修图智能体）
> 主题：拆层之后，生成只进图片墙、切回能还原图层文档；图层与选区升级为两个正交维度按层拆步，并修掉拖角缩放的撤销与计划卡片刷新
> 日期：2026-10-12
> 前置：多步计划与确认执行

## 1. 背景与目标

多步计划落地后，「拆成背景 + 主体」已经是常规操作，但拆层之后的一整套交互还有几个别扭的地方：

1. **生成把画布画崩**。已拆层的画布上再说「换个背景」「扩图」「超分」，工具把整张拍平喂给模型，模型出来的图里必然又带一个主体，写回图层等于把主体画两遍，主体层白拆了。
2. **切走再切回来，图层塌成一张**。从当前图切到图片墙上的别的素材再切回来，画布只剩一张底图，辛苦拆出来的背景层、主体层连同各自的位置都不见了，只能重拆。
3. **图层和选区搅在一起**。局部消除、局部替换要么认选区、要么认图层，说不清「把背景层的这一块改成红色，主体层不动」。想「主体改红、背景改蓝」只能拆成两轮，每轮还得重选一次。
4. **圈选只选中描边**。用笔刷圈住一个物体，真正生效的是那条涂抹带子，圈住的内部反而没被选中，得反复涂满。
5. **拖角缩放撤不干净**。四角手柄缩放会同时移动图层中心，但旧实现只把倍率写回，位置留在画面里靠节点硬撑，一次撤销只回倍率、位置回不去，画面跳一下。
6. **计划卡片停在「等待中」**。多步计划里画布工具当场成功、像素工具排队等 worker，前端只在 SSE 结束时拉一次，下一步还没写进计划就错过了刷新，卡片一直显示旧状态。

本里程碑把这些补齐：让生成尊重已拆的图层、切回能还原文档；把图层与选区拆成两个正交入参按层拆步；笔刷圈选自动闭合成面积；拖角缩放位置与倍率一起写、一次撤销；计划整轮进行时前端持续刷新。

## 2. 用户与场景

| 角色 | 场景 |
|---|---|
| 创作者 | 已拆层后说「换背景」，新背景只进图片墙，主体层一个像素不动，点选满意的那张再采用 |
| 创作者 | 在图片墙上点别的素材再点回当前图，图层结构和位置原样回来 |
| 创作者 | 说「主体改红色、背景改蓝色」，计划自动拆成两步，各自点名图层，共用同一块圈选区域 |
| 创作者 | 用笔刷圈住一个物体，松手即选中圈内整块，不用把里面涂满 |
| 创作者 | 画布上拖角放大某图层，撤销一次即可把大小和位置一起退回原位， redo 再一起回来 |
| 创作者 | 多步计划执行中，步骤卡片状态随每一步完成实时刷新，不会卡在「等待中」 |

## 3. 功能需求

### 3.1 已拆层时整图生成只上墙 F1

- **F1.1** 画布已拆层，或多于一个图像图层时，换背景 / 扩图 / 超分的结果**只作为候选进图片墙**，不写回图层文档、不改当前图、不动修订号。
- **F1.2** 未拆层的单图仍按原样：单张结果自动采用，多张候选进墙等点选。
- **F1.3** 已拆层且只换背景层时，只喂背景层自己的像素给模型，避免把主体一起重画。

### 3.2 切回素材时还原图层文档 F2

- **F2.1** 切换当前图（PATCH `current_asset_id`）时，若该素材在历史上留下过图层文档，切回来要**复用最近一次的文档**，而不是按整图重建一张底图。
- **F2.2** 「最近的文档」从编辑历史里按序号倒序找，优先取该步结果里的文档，其次取变更前快照里的文档，取到即用。
- **F2.3** 从没拆过层的普通素材切走再切回，仍按整图建新文档，行为不变。

### 3.3 图层与选区正交、按层拆步 F3

- **F3.1** 局部工具同时接受两个彼此独立的入参：`layer_id` 决定改哪一层，选区（遮罩）决定改哪块区域；两者都给时取交集。
- **F3.2** `layer_id` 可以是图层 id，也可以是图层名（如「主体」「物体2」），服务端按 id 优先、名字兜底解析；点名不到时报可直接展示的中文错误。
- **F3.3** 只点名图层、没有选区时，作用在**整个该图层**；既不点名也没选区时，作用在选区下最上层图像（没选区则最上层可见图像）。
- **F3.4** 画布摘要里按「自下而上」列出每个图层的 `id=名字`，并说明选区只限定区域、与 `layer_id` 同时给出取交集，供模型据此拆步。
- **F3.5** 一句话涉及多个图层时，模型按图层拆成多步，每步只填一个 `layer_id`。
- **F3.6** 一轮计划里的多个需要遮罩的步骤**共用当轮同一块选区**：规划完成即把遮罩 id 钉进每一步，之后第一步清除选区或修订号递增都不影响后续步骤。
- **F3.7** 选区画幅与当前文档画幅不一致时判为失效并明确报错「画幅已变，选区失效，请重新选择」，不把旧遮罩硬拉伸上去。

### 3.4 笔刷圈选自动闭合成面积 F4

- **F4.1** 三个及以上点构成的笔画自动闭合成填充面积，圈住物体即选中整块；两点及以下的短笔画仍只得到一条带状选区。
- **F4.2** 闭合成面积后仍叠画描边轮廓，自相交乱涂即使填不出内部，涂过的地方也一定被选中。
- **F4.3** 前端笔刷预览按同一个粗细比例画出闭合填充，与实际生成的遮罩一致。

### 3.5 拖角缩放连位置一起写、一次撤销 F5

- **F5.1** 拖角缩放改变图层中心位置时，缩放写入把**倍率与新位置一次落进同一条编辑历史**。
- **F5.2** 一次撤销即可把大小与位置一起退回；redo 再把两者一起带回。
- **F5.3** 缩放写入服务端期间，画布用钉住的中间值维持画面，文档追上后自动撤下钉值，不出现「倍率已改、位置还在旧节点上硬撑」的抖动。
- **F5.4** 松手时不先改 Konva 节点属性（避免 Transformer 已摆好再 `setAttrs` 抖一下），倍率与位置交给 React 一次写入。

### 3.6 计划卡片随整轮进行刷新 F6

- **F6.1** 一轮计划处于 `running` 时，对话区按固定间隔持续拉取，直到整轮进入终态。
- **F6.2** 整轮从 `running` 进入 `succeeded`/`failed`/`canceled` 时，失效当前会话与编辑历史，画布与图层面板同步到最新。
- **F6.3** 切换会话时重置上一轮的跟踪状态，避免跨会话误触发刷新。

## 4. 非功能需求

- **NFR1** 不新增数据库表与列。图层文档、选区、历史都复用既有结构。
- **NFR2** 未拆层的单图场景行为不回退：F1、F2 只在「已拆层或多层」时改变结果去向。
- **NFR3** 局部工具改造不得让旧的「只有选区」调用失效；不点名图层时维持原有「选区下最上层」语义。
- **NFR4** 计划推进不落库再读，避免前端捞到「上一步完了、下一步还没写进计划」的中间态。

## 5. 验收标准

- [ ] 已拆层后 `replace_background`/`expand_canvas`/`upscale_image`：结果只进图片墙，图层文档与修订号不变。
- [ ] 拆层后切到别的素材再切回，`document.layers` 与切走前逐层相等，当前图一致。
- [ ] `replace_region` 不点名图层、无选区时改整层；点名 `subject` 或「主体」时只动主体层。
- [ ] `layer_id=background` + 命中主体的选区 → 只改交集；选区没覆盖到点名图层时报「没有覆盖」。
- [ ] 点名不存在的图层名报「图层不存在」，可展示。
- [ ] 三点及以上笔画：圈住点被填充，圈外角落不被选中。
- [ ] 拖角缩放写入 `x/y` 后，撤销使 `scale_x` 与 `x/y` 一起回到初值，redo 再一起回来。
- [ ] 一轮计划 `running` 时对话按间隔刷新；进入终态后画布与历史失效重取。

## 6. 范围与非范围

**在范围内**：已拆层生成的去墙策略、切回还原文档、图层×选区正交入参与按层拆步、选区钉进多步、画幅变更遮罩失效、笔刷闭合填充、拖角缩放位置随倍率写入并支持整体撤销、计划卡片持续刷新。

**不在范围内**：跨会话共享选区、把遮罩暴露为可编辑结构、并行走无依赖步骤、图层名的模糊匹配或别名表。

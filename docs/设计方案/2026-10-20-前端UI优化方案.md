## 当前问题与对应改动

| 位置 | 当前表现 | 设计改动 |
| --- | --- | --- |
| 首页 | 首屏为居中标题和输入框，图片产品的输出效果要向下滚动才出现 | 左侧讲清用途与开始入口，右侧展示实际效果示例；示例明确标识，不能冒充用户结果 |
| 全局导航 | 默认只显示图标，悬停后覆盖内容展开；触屏与键盘用户难发现文字 | 非编辑页面固定显示图标与文字；编辑页面用明确开关收起，收起后仍保留短标签 |
| 创作页 | 生图、上传、历史素材纵向堆叠，缺少主要任务引导 | 生图输入为主区域，上传修图为并列入口；最近创作进入首屏下半区 |
| 编辑顶部 | 标题、十余个工具、撤销、对比、缩放、导出共用横向滚动区域 | 第一层放标题与导出，第二层按用途呈现常用工具；视图控制移至画布底部 |
| 编辑侧栏 | 左侧固定 288px 对话栏，窄屏进一步压缩画布 | 桌面将助手与图层放到右侧标签面板；窄屏按需弹出，一次展示一个面板 |
| 控件与文字 | 多处 10–12px 小字、浅色提示、较重面板阴影 | 正文 14–16px、辅助信息 12–13px，提升对比度；用细边线与背景层级替代大面积投影 |
| 导出与批量 | 以选择器和表单为主，结果预期不够直观 | 导出采用尺寸选择与预览；批量按选图、步骤、执行分段组织 |

现有进度、禁用、确认、错误与撤销逻辑已有实现。重设计保留其语义，重点调整位置和表达，不把已有能力当作缺失功能重新开发。

## 方向比较

1. **轻量修图工作室（推荐）**：暖灰底色、白色面板、深青绿操作色，以作品、画布和操作为视觉重心。适合当前电商修图与内容创作定位。
2. **深色专业编辑器**：深灰画布、紧凑工具与高密度属性面板。适合长时间专业编辑，但会增加新手理解成本，也需要完整设计暗色状态。
3. **作品图库工作台**：以大幅图片和最近项目为首页主体。适合素材多、复用频繁的用户，但当前生图与上传入口仍需优先展示。

## 推荐视觉规范

| 角色 | 值 | 使用范围 |
| --- | --- | --- |
| 页面底色 | `#F5F4F0` | 创作、导出、批量背景 |
| 内容面板 | `#FFFFFF` | 导航、输入、属性面板 |
| 主要文字 | `#202B2A` | 标题、正文、工具名称 |
| 辅助文字 | `#63706C` | 说明、尺寸、时间 |
| 边线 | `#E0E4DF` | 分区与控件 |
| 操作强调 | `#246B5B` | 主按钮、选中状态、键盘焦点 |
| 轻强调底色 | `#EDF4EF` | 当前导航、选中条目 |

- 字体沿用本地中文系统字体，不新增远程字体依赖。
- 面板圆角 14px，控件 8px；浮层保留必要阴影。
- 内容区最大宽度约 1200px；编辑器铺满剩余空间。
- 页面标题 28–32px，分区标题 16–18px；不使用大量超大标题。
- 使用统一 SVG 图标，不用 Emoji；悬停仅改变颜色与边框，不移动布局。
- 动效 150–200ms；尊重减少动态效果设置。
- 第一版明确以浅色界面交付。暗色编辑器作为后续完整设计，不增加无效主题开关。

## 页面结构

### 创作页

顶部：当前工作空间与页面名称。

中部：一句简短引导；左侧生图输入、比例与数量、生成按钮；右侧上传入口与支持格式。输入框下提供少量真实可用的提示词预设，点击只填入内容，由用户提交。

下部：最近创作缩略图。沿用现有素材分组及打开会话的能力，显示实际数据。空态保留说明与上传入口，不注入演示作品。

### 编辑页

顶部第一行：标题、画布尺寸、撤销/重做、对比、导出。导出保持稳定可见。

工具区：选区、裁剪、去背景、换背景等常用工具。翻转、扩图、超分、调色、拆层按分组进入更多工具；选择与裁剪模式仍呈现各自的上下文控件。

中央：中性画布与真实图片，保留 Konva、选区、裁剪和前后对比。底部放版本缩略图与缩放、适应画布操作。

右侧：AI 助手、图层两个主标签。调色、替换、背景等工具打开对应参数内容；标签切换不清空输入、会话或工具状态。保留历史会话入口，不额外占用一整列。

助手消息：区分用户指令、待确认计划、运行阶段和结果。继续使用实际任务状态，不能用固定百分比或装饰进度制造完成感。

### 首页、导出、批量

- 首页：产品说明与图片效果并列，明确区分“上传编辑”和“描述生成”。未登录时先登录，已有提示词继续保留。
- 导出：左侧选择物料和尺寸，右侧预览；选择汇总、错误提示和下载入口保持可见。
- 批量：选图 → 配置处理步骤 → 检查与执行，保留最多 20 张、历史任务、实际进度与结果打包。

## 响应式与交互边界

- 1440px：完整导航、画布与右侧面板，中央画布优先分配空间。
- 1024px：编辑导航收窄，属性面板可折叠；标题与工具分行。
- 768px：编辑侧栏作为抽屉打开，遮罩点击或 Esc 关闭；非编辑页面内容重新排列。
- 375px：导航显示可点击的短标签；表单单列；工具换行或明确进入更多；页面不依赖横向滚动寻找主操作。
- 所有触屏关键操作的有效点击区域至少约 44px；键盘焦点清楚可见。
- 弹出菜单及抽屉支持键盘、焦点管理和关闭后焦点回到触发按钮。
- 选区、裁剪、画布操作与输入框快捷键保持当前边界。

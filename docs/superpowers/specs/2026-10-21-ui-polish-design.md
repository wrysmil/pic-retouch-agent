# 前端轻量视觉升级

目标：保留现有操作方式，通过插画、排版与表面质感提升产品完成度。

选择：沿用现有蓝绿品牌色，以暖白背景、深墨绿文字、少量青柠点缀构成安静的创意工作室风格。相比整站卡通化，这一方向更适合高频编辑；相比纯样式微调，加入原创修图小助手更有识别度。

范围：首页仍保留居中的需求输入、场景快捷按钮、能力卡片与现有入口。首屏输入下加入小助手与图片卡片组成的插画横幅。登录页增加桌面端品牌插画面板，移动端以表单为主。创作页优化标题、区块层次与空状态。上传区、输入面板和工作台导航做样式微调。

约束：不改变路由、表单字段、快捷键、提交/上传/登录逻辑、编辑器布局、后台独立设计系统。不增加依赖。不修改已有的非本次工作区变更。装饰图片使用空 alt，响应式布局不溢出，尊重减少动态效果偏好。

素材：使用内置 ImageGen 生成原创奶白与蓝绿色 3D 修图相机小助手和图片画框；压缩为 WebP，存入 frontend/public/illustrations。无文字、无商标，保留生成提示词记录。

验证：工作台与后台生产构建、前端 lint、浏览器桌面与移动截图；检查快捷提示词、登录/注册切换、草稿跳转及创作页表单原交互。

追加需求：能力卡片改用摄影质感的商品图片，采用同一陶瓷杯的四种场景。品牌展示名统一为「映造」，覆盖首页头尾、工作台、登录页及前后台浏览器标题。保留内部 API、存储键及工程名称。

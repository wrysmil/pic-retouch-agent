# 前端轻量视觉升级执行计划

目标：在原有交互上加入统一的视觉细节和原创插画。

1. 记录现有路由、表单、上传与快捷键行为；保留全部处理函数。纯样式与装饰内容变更不新增镜像实现的单元测试，以浏览器验证为主。
2. 生成一张原创小助手插画，检查画面并压缩入 public/illustrations，记录来源与提示词。
3. 首页：保留输入区与场景按钮，优化标题、输入容器、能力卡片，加入装饰性插画横幅。
4. 登录/创作页：独立并行修改两个页面的展示标记与 Tailwind 样式；保持字段、校验、提交逻辑、顺序。
5. 公共样式：微调工作台颜色、卡片阴影、上传区域与导航，不改变后台 ad-* token。
6. 执行 npm run build:all 和 npm run lint；用浏览器检查桌面/手机、首页场景按钮与草稿跳转、登录/注册切换、创作比例数量/排除项，检查装饰图片载入和横向溢出。后端不可用时用仅浏览器的 mock 验证 UI 并注明边界。
7. 检查最终 diff，记录验证结果，保留用户已有变更，不提交或部署。

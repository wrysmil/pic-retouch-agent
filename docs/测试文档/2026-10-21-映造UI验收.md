# 映造 UI 轻量升级验收

## 范围

沿用原有页面和操作方式。修改前台配色、卡片、输入区、上传区和导航样式；为首页、登录页、创作页增加原创小助手插画；四张能力卡片换为摄影质感的陶瓷杯示例图。品牌名统一为「映造」，后台仅改浏览器标题。

## 验证结果

- `npm run build:all`：工作台与后台均通过，包含 TypeScript 编译；工作台仍有大于 500 KB 的原有打包提醒。
- `npm run lint`：退出码 0；现有编辑器/hooks/AdminModels 中仍有 React 相关警告。
- 修改文件的定向 oxlint：退出码 0，无警告。
- `git diff --check`：通过。
- 浏览器：检查 1280px 登录页、1024px 功能卡片、390px 首页/创作页、320px 创作页与功能卡片。320px 页面 scrollWidth 与 clientWidth 均为 320；手机插画未覆盖正文，尺寸预览无相邻场景泄露。
- 交互：商品主图场景填入；免费开始转登录；草稿回填；登录/注册切换；比例 9:16、数量 2 选择；排除项展开与填写；空描述禁用生成；Shift+Enter 换行；模拟接口错误仍显示反馈。
- 素材：3 个 WebP 共 92,386 字节；生成来源与完整提示词见 frontend/public/illustrations/README.md。

## 验证边界

未连接后端运行真实生成、上传或登录任务。需要登录状态的页面在临时本地预览壳中用静态用户和空素材响应验收，未绕过正式应用鉴权、未发起模型调用。预览壳已移除。

## 2. 提交 2：后端逻辑

### 2.1 编辑层 `backend/app/edits/document.py`

- 导入 `LayerKind`、`LayerMissing`。
- `set_text(document, layer_id, text, *, font_size=None, fill=None)`：深拷贝文档，`_resolve_text` 取目标层，写 `layer.text`，并把 `layer.name = text[:12] or layer.name`；`font_size`/`fill` 仅在传入时覆盖。
- `_resolve_text(document, layer_id)`：点名走 `resolve_layer`，非 `TEXT` 抛 `EditError("只能改文字图层的文案")`；未点名倒序找第一个可见 `TEXT` 层，找不到抛 `LayerMissing("没有可编辑的文字图层")`。
- `__all__` 增 `"set_text"`。

### 2.2 拆层像素 `backend/app/edits/split.py`

- 导入 `ImageDraw`。
- `text_mask(size, boxes, *, grow=None)`：`L` 模式黑底画白矩形，`grow`（默认 3）转成 `MaxFilter(radius*2+1)` 外扩，返回 `overlay_png(mask)`。
- `remove_text(subject, background, boxes, size)`：`boxes` 为空直接原样返回；否则 `hole = text_mask(...)`，返回 `(punch(subject, hole), fill_background(background, hole))`——主体挖空、背景用周围色填。

### 2.3 合成 `backend/app/edits/render.py`

- 导入 `os`、`ImageDraw`、`ImageFont`；新增 `_FONT_PATHS`（macOS 苹方/冬青/黑体 + Linux 文泉微米黑 + Noto CJK）与模块级缓存 `_font_file`。
- `flatten(..., include_text: bool = True)`：主循环改为先判 `not visible` 跳过；`TEXT` 层 `include_text` 时调 `_composite_text` 后 `continue`；`IMAGE` 层解码、`resize` 后交给新的 `_place`。
- 原 `_composite` 拆成 `_composite_text`（按 `layer.text ?? layer.name` 居中绘制、`_font`/`_rgba` 上色取字号，空文案直接 return）与 `_place`（承接镜像/旋转/位移粘贴）。
- 新增 `_font(size)`（`truetype` 失败退 `load_default`）、`_font_path()`（探测首个存在路径并缓存，全缺则缓存空串）、`_rgba(fill)`（去 `#`、三位补六位、非六位回退 `(20,20,20,255)`）。

### 2.4 工具与上下文

- `tools/canvas.py`：导入 `set_text`；`TextIn(LayerRef)` — `text: str = Field(max_length=500)`、`font_size: float|None = Field(default=None, ge=8, le=400)`、`fill: str|None = Field(default=None, pattern=r"^#(?:[0-9a-fA-F]{3}|[0-9a-fA-F]{6})$")`；`set_layer_text` handler 走 `_apply`，`fill`/`font_size` 用 `params.get(...)` 可缺省；注册 `SET_LAYER_TEXT = _canvas("set_layer_text", "改文字", "…未指定图层时改最上层可见文字。", TextIn, set_layer_text)`。
- `tools/__init__.py`：`SET_LAYER_TEXT` 加入 canvas 导入（`SET_LAYER_OPACITY` 与 `SET_LAYER_VISIBLE` 之间）与 `SPECS`（`SET_LAYER_VISIBLE` 之后、`REORDER_LAYER` 之前）。
- `tools/context.py`：`flatten_session(..., include_text: bool = True)` 透传给 `flatten`，补 docstring 说明 `False` 供成层等保留矢量字的像素操作。
- `tools/layers.py`：`split_layers_exec` 在 `include_text` 且 `detect_text` 出结果后，`size = Image.open(source).size`，`subject, background = await asyncio.to_thread(remove_text, subject, background, texts, size)`；`promote_object_exec` 改 `flatten_session(session, record, include_text=False)`。
- `agent/graph.py` 系统提示词新增「改文字图层的文案、字号或颜色用 `set_layer_text`，并点名图层」。

### 2.5 容器 `Dockerfile`

运行阶段装 `fonts-wqy-microhei`（`--no-install-recommends`，装完清 `apt` 缓存），供 `_composite_text` 在 Linux 命中 `wqy-microhei` 字体。

## 4. 提交 4：前端

### 4.1 预览合并 `frontend/src/stores/editorUi.ts`

- `LayerPreview` 增 `font_size?: number`、`fill?: string`、`text?: string`。
- `setLayerPreview` 改为：`null` 清空；与当前 `layerPreview.id` 相同则 `{...prev, ...layerPreview}` 合并（文字/字号/颜色可与位置预览共存），否则整体替换。

### 4.2 画布行内编辑 `frontend/src/components/editor/CanvasStage.tsx`

- 新增 `onEditText` prop；`holdingStage`/`editingId` 状态上移到 `useEffect` 之前；派生 `editing`（从 `canvas.layers` 找 `editingId` 对应的 `text` 层）、`selecting`/`interactive`/`stageDraggable`。
- 两个 effect：`!interactive` 清 `editingId`；`editingId` 存在但 `editing` 已消失（层被删/切走）也清。
- Stage `onDblClick` 加 `event.target !== stage` 判定，双击空白才 `fit`。
- `DocumentLayer` 收 `editingId`/`onEdit`；`LayerScaler` 渲染条件加 `editingId !== selected.id`（编辑时收起手柄）。
- `TextLayer` 收 `editing`/`onEdit`：`useLayerInteract` 的 interactive 传 `interactive && !editing`；文本 `text/fontSize/fill` 优先取 `preview`，`opacity` 编辑时置 0；新增 `onDblClick`（选中并进入编辑、`cancelBubble`）；`stroke/strokeWidth` 加 `&& !editing`。
- 新增 `TextEditor` 组件：受控 `textarea`，`useEffect` 聚焦全选；`finish` 用 `done` 防重入，Enter（非 Shift）/失焦提交、Esc 取消；按 `view.x/y + transform.scale` 定位，字号、颜色、行高、旋转与图层对齐。
- 编辑框挂在 `</Stage>` 之后：`onCommit` 清 `editingId`，内容变化才 `onEditText?.(editing.id, text)`。

### 4.3 其余前端

- `pages/EditorPage.tsx`：`CanvasStage` 加 `onEditText={(layer_id, text) => tools.invoke('set_layer_text', { layer_id, text })}`。
- `components/editor/LayerPanel.tsx`：选中文字层时渲染「文字」`<Section>` 挂 `TextForm`，`onCommit` 走 `set_layer_text`（点名 `selected.id`）；新增 `TEXT_FIELD` 样式常量、`toHex6`（三位补六位）、`TextForm`（文本框 + 字号 `SliderField` 8–120 + `<input type=color>`，输入即 `setLayerPreview({id, …})`，失焦/⌘Enter/改色才 `commit`，与当前层等值不提交）；`LayerControls` 预览清除判定补 `text`/`font_size`/`fill` 三项（`toLowerCase` 比色）。
- `api/sessions.ts`：`ACTION_LABELS` 加 `set_layer_text: '改文字'`。
- `lib/runPacing.ts`：`SECONDS` 加 `set_layer_text: 0.8`。

前端改动通过 `tsc -b` 与 `oxlint` 校验；`TextForm` 的 `useEffect` 依赖列表与参考一致（`layer.id/text/font_size/fill`），面板提交刻意留全量依赖以匹配既有 `exhaustive-deps` 约定。

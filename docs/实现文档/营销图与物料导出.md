## 2. 提交 2：营销图与投放尺寸

### 2.1 `app/edits/pixels.py`

两个纯像素函数，放在既有 `_png` 之前复用：

- `resize_to(data, width, height)`：转 RGBA，尺寸不同才 LANCZOS 重采样，一致也重编码为 PNG。营销图生成后统一收口到目标尺寸。
- `letterbox(data, width, height, fill=白)`：按 `min(宽比, 高比)` 等比缩放，贴到目标画幅正中留白，绝不裁切。投放尺寸的核心——主体完整优先于铺满。

### 2.2 `app/ratios.py`

- `matches_ratio(w, h, ratio)`：交叉相乘判等比，不引入浮点。
- `ratio_of(w, h)`：先精确命中 `SIZES`，再退回等比判定，反查投放比例，供打包给文件命名与清单使用；对不上返回 `None`。

### 2.3 `app/tools/marketing.py`（新增）

`MarketingKind` 四类各配一段固定提示词 `_PROMPTS`。两个入参模型：

- `GenerateMarketingIn`：`kind` + 可选 `caption`（≤200） + `count`（1–4） + `ratio`（默认 1:1）。
- `PrepareDeliverySizesIn`：`ratios` 默认 `DELIVERY_RATIOS`、去重、上限为比例总数；带一句「不要裁切商品」的默认 `prompt`。

执行：

- `generate_marketing_exec`：`flatten_session` 拍平当前画布 → provider `edit(...)`（带 `on_progress` 转 `runs.report`）→ `resize_to` 收口 → `_store(kind=MARKETING, ...)`。`queued=True`。
- `prepare_delivery_sizes_exec`：拍平 → 逐个比例 `letterbox` → `_store(kind=EXPORT, ...)`。`queued=False`，纯本地当场完成。
- `_store`：逐个 `assets.create_from_bytes`，返回 `asset_ids` 与逐项 `variants`；`_unique` 给投放比例去重。

两个 `ToolSpec` 描述都强调「只进图片墙，不改画布」，投放尺寸明确「不要用 crop_canvas」。

### 2.4 注册与提示词

`app/tools/__init__.py` 在 `PROMOTE_OBJECT` 之后登记 `GENERATE_MARKETING`、`PREPARE_DELIVERY_SIZES`。`app/agent/graph.py` 系统提示词加两条规则，把「出营销图/主图/场景/模特/海报」「改尺寸/出投放物料」分别映射到这两个工具。

### 2.5 测试

- `test_generate_marketing_stays_on_the_wall`：断言 `current_asset_id` 不变、`revision==1`、恰 1 张 1080×1080 marketing。
- `test_prepare_delivery_sizes_covers_three_ratios`：断言三个尺寸齐、画布未动。
- `test_marketing_tool_is_planned_and_dispatched`：fake planner 下发 `generate_marketing`，轮次 `running`、步骤标签「营销图」。

## 3. 提交 3：打包导出接口

### 3.1 `app/schemas/export.py`（新增）

`ExportIn{asset_ids}`、`ExportItemOut`、`ExportManifestOut`、`ExportOut`，以及 `EXPORT_KINDS = (MARKETING, EXPORT)` 作为默认收集范围。

### 3.2 `app/services/exports.py`（新增）

- `PackedExport` 冻结数据类，`disposition` 用 `quote` 生成 `filename*=UTF-8''…` 支持中文名。
- `_safe_name`：正则只保留 `\w`、中日韩统一表意文字、连字符与空格，空格转连字符，截 40 字，空则「物料」。
- `_pick`：显式 `asset_ids` 逐个按图片墙校验，缺一个抛 `UnknownExportAsset`；为空则过滤 `EXPORT_KINDS`。
- `_pixels`：素材为空或等于 `current_asset_id` 时用 `flatten_session` 合成画布（当前图以最新文档为准），否则读对象存储。
- `pack`：无可打包项时退化为单张当前画布；内存 `zipfile` 逐张 `probe` 出尺寸、`ratio_of` 反查比例，命名 `images/NN-kind-slug.ext`，写完各项再写 `manifest.json`（`ensure_ascii=False`），文件名 `安全标题-YYYYMMDD.zip`。

### 3.3 `app/routers/sessions.py`

新增 `POST /{session_id}/exports`，先 `_load` 走归属校验（他人会话 404），`exports.pack` 捕获 `UnknownExportAsset` 转 422，成功用 `Response(media_type="application/zip", Content-Disposition=…)` 直接回字节流。

### 3.4 测试

`test_exports.py`：空物料打包含当前画布、投放尺寸三项与清单、当前图以合成画布为准、外部素材 422、跨用户 404。

fixture 调整：`other_credentials` 原是 `test_sessions.py` 的模块级 fixture，跨模块不可见，且 `test_` 前缀的用户不会被 conftest 的 `TEST_USER_PREFIX` 清理。上移到 `conftest.py` 并改用 `TEST_USER_PREFIX`，`test_sessions.py` 删除本地定义，`test_exports.py` 直接按名取用——同时消除 `ruff F811` 的导入即参数同名告警。

## 4. 提交 4：导出物料页面与导航

### 4.1 `api/sessions.ts` / `hooks/useSessions.ts`

- `ACTION_LABELS` 补 `generate_marketing`、`prepare_delivery_sizes` 两个中文名。
- `sessionsApi.export` 走原生 `fetch`（`api` 封装默认解析 JSON，不适配二进制），非 2xx 用 `ApiError` 抛后端 `detail`，成功从 `Content-Disposition` 解出文件名，回 `ExportPack{blob, filename}`。
- `useExportPack(id)`：`useMutation`，失败 `toast(errorMessage, 'danger')`。

### 4.2 `lib/marketing.ts` / `lib/format.ts`

- `marketing.ts`：`MARKETING_KINDS`、`DELIVERY_RATIOS` 常量与 `KIND_LABELS`；`ratioLabel` 反查标准尺寸标签；`packable`（遮罩不进包，主体/背景仅在为当前图时进包）；`defaultSelected`（优先营销图与投放尺寸，否则当前画布）。
- `format.ts`：`shortTitle` 折叠空白并按长度截断加省略号。

### 4.3 `pages/MarketingPage.tsx`（新增）

`/marketing` 为 `Picker`（素材库选图，点图即建会话并进入），`/marketing/:sessionId` 为 `Workspace`：顶部当前画布摘要 + `SessionSwitch`；四类 `KindCard` 共享文案输入；投放尺寸「一次三个」与「单个比例」按钮；底部 `PackList` 支持全选/逐项勾选与打包下载（`URL.createObjectURL` 触发 `<a download>`）。生成期间用 `tools.busy/pendingStage/pendingProgress` 禁用并显示进度。

### 4.4 路由与导航

`App.tsx` 用 `MarketingPage` 替换原 `/marketing` 占位，新增 `/marketing/:sessionId`；`WorkbenchLayout` 导航加「导出」项；`EditorToolbar` 工具栏加跳 `/marketing/:id` 的「导出」链接。

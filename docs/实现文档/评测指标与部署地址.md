## 2. 提交 2：部署地址拆分与启动说明

### 2.1 `app/config.py`

在 `s3_endpoint` 之后新增：

```python
# 浏览器打开签名 URL 的地址；空则与 s3_endpoint 相同
s3_public_endpoint: str = ""
```

默认空字符串，本地开发不设即回落 `s3_endpoint`，行为零变更。

### 2.2 `app/storage.py`

`_client` 增加可选形参并保持 `@lru_cache`（缓存键含入参，两套地址各缓存一个客户端）：

```python
@lru_cache
def _client(endpoint: str | None = None):
    ...
    endpoint_url=endpoint or settings.s3_endpoint,
```

`signed_url` 是**唯一**用公网地址的地方——签发即浏览器可见：

```python
return _client(settings.s3_public_endpoint or None).generate_presigned_url(...)
```

其余 `ensure_bucket` / `put` / `get` / `delete` 仍调 `_client()`，走 `s3_endpoint`（容器内网名）。读写与签发因此解耦：容器里 `S3_ENDPOINT=http://minio:9000` 供互访，`S3_PUBLIC_ENDPOINT=http://localhost:7313` 供浏览器打开签名直链。

### 2.3 `.env.example`

`S3_ENDPOINT` 下补 `S3_PUBLIC_ENDPOINT=` 与一行注释，说明「空则同 `S3_ENDPOINT`，deploy profile 由 compose 覆盖」。

### 2.4 `docker-compose.yml`

`app` 与 `worker` 两个 deploy-profile 服务，在各自 `env_file: .env` 之后加同一段 `environment`，用容器内网服务名覆盖、公网地址留给签名：

```yaml
    environment:
      DATABASE_URL: postgresql+asyncpg://retouch:retouch_dev@postgres:5432/retouch
      REDIS_URL: redis://redis:6379
      S3_ENDPOINT: http://minio:9000
      S3_PUBLIC_ENDPOINT: http://localhost:7313
```

`environment` 优先级高于 `env_file`，因此用户 `.env` 里的 localhost 不必为容器部署改动。

### 2.5 `README.md`

保留原有文生图链路链接，追加五节：依赖、环境变量（含 `S3_PUBLIC_ENDPOINT`/`MATTING_PROVIDER`/`OCR_PROVIDER` 表）、端口一览、本地启动、`--profile deploy` 部署、测试与评测。端口沿用既有 7301/7302/7311/7312/7313/7314，CV 模型 `~/.u2net` 由 `cv_models` volume 共享。

## 3. 提交 3：评测包

新增 `app/eval/` 子包，五层单向依赖：`__main__` → `runner` → {`cases`,`tasks`} → `metrics`；`__init__` 只导出 `evaluate`/`render`。

### 3.1 `tasks.py`：任务名 → 确定性像素函数

`TASKS: dict[str, TaskFn]` 把六个评测任务名映射到 `app.edits.pixels` 的纯函数，统一签名 `(data: bytes, params: dict) -> list[(label, bytes)]`：

- `remove_background` / `adjust_image`：`_one(...)` 产出单张，label 即任务名。`adjust_image` 从 params 里只挑 `adjust` 认识的白名单键透传。
- `letterbox` / `resize`：按 `params` 的 width/height，label 为 `宽x高`。
- `prepare_delivery_sizes`：params 无 ratios 时用 `DELIVERY_RATIOS`，逐比例 `letterbox` 并按 label 去重，一用例产出多张。
- `encode`：按 `format`（默认 png）。

`run_task(name, data, params)` 对未知任务名抛中文 `ValueError` 并列出可选项。复用营销/批量已落的 `encode`、`letterbox`、`resize_to`，评测口径与线上同源。

### 3.2 `metrics.py`：像素指标与方向

纯 PIL 计算，不含 IO/DB：

- `aligned()`：预测/期望尺寸不一致时最近邻缩放预测图，保证逐像素可比。
- `mae` / `psnr`：对 RGBA 全通道逐字节；`psnr` 在 mse=0 时返回 99 上限。
- `alpha_iou`：按 alpha>阈值取掩膜，返回交并比；无前景并集时视为 1。
- `size_score` / `image_size`：命中目标宽高为 1。
- `subject_bbox` + `contain`：不透明像素外接框经 letterbox 等比内缩后，落在输出画幅内的面积比例。
- `passes(name, value, threshold)`：方向写死——`_LOWER_IS_BETTER={mae}` 取「≤」，`_HIGHER_IS_BETTER={alpha_iou,psnr,contain,size}` 取「≥」，未知指标默认「≥」。

### 3.3 `cases.py`：用例读取

- `Case`（pydantic）：`id`/`task`/`input`/`expect?`/`params`/`metrics`/`thresholds`，`input_path`/`expect_path` 相对数据集根解析。
- `load_cases`：缺 `cases.json` 抛 `FileNotFoundError`（带示例文件指引），非空数组校验，未知任务名汇总后抛 `ValueError`——两者被 CLI 捕获为退出码 2。
- `expect_size_of`：`letterbox`/`resize` 取 params 宽高，`prepare_delivery_sizes` 用 `size_of(Ratio(label))` 反查标准画幅，其余返回 None（由 runner 回落参考图尺寸）。

### 3.4 `runner.py`：跑批、打分、渲染

- `DEFAULT_THRESHOLDS` 给五指标默认线；`_SCORERS` 把 `mae/psnr/alpha_iou/contain` 归一成 `(pred,expect,source)->float`（`contain` 用 `(source,pred)`）。
- `_score_output`：逐指标算分并 `passes` 合成 `ok`；`size` 走 `expect_size_of`→参考图尺寸→报错的三级回落；必需参考图而缺失则抛错。
- `evaluate_case`：读源图、`run_task` 产出；`expect` 若为**目录**则按 label 找 `{label}.png` 分别比对（投放尺寸多产出），否则单参考图；整段 `try/except` 把异常收进 `CaseResult.error`，不使全批崩溃。
- `evaluate`：`load_cases` 后逐例执行。
- `render`：列名取所有用例指标去重、按首次出现排序；逐产出成行，非同名任务 label 带 `/比例`；末行 `{passed}/{total} passed`。`_fmt` 去掉尾随 0。
- `__main__.main(argv)`：解析目录参数，`FileNotFoundError`/`ValueError` 打 stderr + 示例指引并返回 2，否则打印表格，返回 `0 if all ok else 1`。

### 3.5 仓库配置

- `pyproject.toml`：`[tool.ruff]` 增 `exclude = ["migrations"]`，评测/工具改动触发全量 lint 时不再被 Alembic 生成文件的历史超长行干扰。
- `.gitignore`：新增 `evals/` 段——用户自备评测素材的落点不入库。
- `cases.example.json`：三条示例（抠图 `alpha_iou`、调色 `mae`+`psnr`、投放尺寸 `size`+`contain`），兼作格式契约。

### 3.6 `tests/test_eval.py`

纯函数级 + CLI 级，不碰 DB：`mae/psnr` 同图为 0/上限；`alpha_iou` 对已知 6×6∩6×6 掩膜等于手算 4/68；letterbox 的 `size`+`contain`；投放尺寸比例顺序与命中；`passes` 方向；`tmp_path` 造数据集跑 `evaluate`+`render`+`main` 断言 `2/2 passed` 且退出码 0；缺 `cases.json` 时 `main` 返回 2 且 stderr 含提示；设 `s3_public_endpoint` 后 `signed_url` 前缀与签名参数、finally 复位并 `cache_clear`。

> 说明：本仓库集成测试套件的会话级 fixture 会连 MinIO，故 `test_eval` 在离线环境以「收集通过 + 逻辑经 `python -c` 旁路验证」为准；地址与评测函数本身不依赖网络。

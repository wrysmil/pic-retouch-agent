## 2. 提交 2：接口报错 / 翻转文案 / 裁切切图 / 只上墙历史

### 2.1 后端

- `tools/base.py`：`ToolSpec` 加 `detail: Callable[[dict], str | None] | None`，并给出 `label_for(params)`——`detail` 命中就用细分说法，否则回落 `label`。
- `tools/canvas.py`：`_canvas(...)` 增 `detail=None` 形参并透传进 `ToolSpec`；`FLIP_LAYER` 传 `detail=lambda p: _FLIP_LABELS.get(p.get("direction"))`，`_FLIP_LABELS={"horizontal":"水平翻转","vertical":"垂直翻转"}`。
- `tools/__init__.py`：`label_of(name, params=None)` 改走 `spec.label_for(params)`。
- `agent/graph.py`、`schemas/agent.py`：拼标签处传入 `step.get("params")`，单步 / 多步 / 播报同源。
- `services/sessions.py`：`switch_current` 先取该图上次文档，若 `_cropped_base(document, asset)`（单 base 层、同资产、画幅小于素材原尺寸）则改用 `document_of(asset)` 取原生画幅；点当前图本身时，仅当它「被裁过」才写回原生画幅并递增 revision，否则直接返回不产生空记录。新增私有 `_cropped_base`，并从 `app.layers` 引入 `BASE_LAYER_ID`。
- 只上墙仍留记录依赖 `_attach` 返回新增数 + `apply_edit` 的 `if not changed and not added` 短路（此前里程碑已落），本提交仅补齐对应回归用例。
- 测试：`test_agent` 加翻转方向标签用例；`test_sessions` 加「裁过再点回恢复原尺寸」用例（引入 `tests.canvas.invoke`）；`test_tools` 给候选图上墙补 history 断言并加「拆层后扩图只进墙」用例。

### 2.2 前端

- `api/client.ts`：新增 `messageOf`（递归取 `msg`/`message`、剥 `^Value error,`）、`formatDetail(detail, fallback)`（数组用中文「；」连接）、导出的 `apiError(response, fallback)`；`request` 与 `assets/batches/sessions` 三处原生 fetch 错误统一经 `apiError`。
- `lib/layers.ts`（新增）：`wallOnly(document)`——多图像层、或含 background(+subject)、或有 background 无 base 时为真，对齐后端 `_layered`。
- `EditorToolbar.tsx`：根 `header` 加 `scrollbar-slim overflow-x-auto`；超分按钮 title 依 `wallOnly` 切换。
- `GenerateEdits.tsx`：`BackgroundForm`/`ExpandForm` 增 `wallOnly` 形参，说明文案按是否只上墙切换。
- `LayerPanel.tsx`：`onlyToWall = wallOnly(session.document)`，传入两表单。
- `useElementSize.ts`：改 `useLayoutEffect` 先量一次 `clientWidth/Height`，`measure` 遇 0 沿用上值，避免首帧 0×0 舞台画不出、视图无法适应。
- `useSessions.ts`：`useSessionTools` 增 `isRunning(tool, match?)`，据 `invoke.variables` 判定「当前跑的是否这次调用」，供按钮只给发起者显示进行态。
- `canvasView.ts`：新增 `awaitingFit`——视口未量出时暂存 fit 目标，`setViewport` 拿到真实尺寸后补一次 `fit(..., animate:false)`。
- `editorUi.ts`：`withoutReplace(panel)` 在开裁切 / 对比 / 选择模式时收起依赖选区的局部替换表单。
- `AuthPage.tsx`：`RULES` 按登录 / 注册给 `minLength/maxLength/pattern/title`，透传进 `<input>`，注册侧浏览器原生拦截。
- `EditorPage.tsx`：根容器 `overflow-hidden`，防工具条 / 画布撑出滚动把画布滚出视口。
- `MarketingPage.tsx`：`deliveryRunning(ratio?)` + `isRunning` 让「生成三尺寸 / 单比例」按钮与营销卡各自显示进行态；`PackList` 的 `busy` 拆成 `disabled`（禁用）与 `packing`（打包文案）。

## 3. 提交 3：切图过渡 + 选区即时预览 + 生成进度（后端部分）

- `edits/segment.py`：`warm_embedding(image)`——`corner` 直接跳过，否则算整图 embedding 塞缓存；`rembg` 下失败上抛。供进入点选前预热，点击只跑 decoder。
- `services/selections.py`：`prepare(session, record)` = `flatten_session` 后 `to_thread(warm_embedding, source)`；引入 `warm_embedding`。
- `routers/sessions.py`：新增 `POST /{session_id}/selection/prepare` 返回 204，调 `selections.prepare`。
- `providers/dashscope.py`：`_await_result` 记录 `started`，`PENDING` 固定 `(10, 排队中)`，`RUNNING` 按已等待秒数 `min(82, 38 + waited/2.2)` 平滑上探，替代原先恒定的 `(45, 生成中)`。
- `tests/test_tools.py`：加「选择准备接口返回 204」用例。

前端部分（`CanvasStage`、`SelectionOverlay`、`useCanvasImage`/`useHeldCanvas`/`usePointPreview`/`useSelection`/`useSelectStroke`、`lib/floodPreview`/`selectionHistory`、`useRun`/`useSmoothedProgress`、`EditorPage`、`canvasView`）落地一致的切图过渡与本地即时预览：进点选先打 prepare、笔刷 / 点选渲染预览层、切图时旧修订选区失效且过渡平滑。移植时对齐本仓库既有 Konva 舞台结构逐文件改写，`tsc`+`oxlint` 兜底。

## 2. 提交 2：生成去墙与切回还原文档

### 2.1 `backend/app/tools/enhance.py`

新增 `_layered(document)` 判定：`already_split(document)` 或图像图层数 `> 1` 即视为已拆层。据此改变三个像素工具的结果去向：

- `replace_background_exec`：算出 `wall_only = _layered(document)`。已拆层时只喂背景层自己的像素（`layer_image`），未拆层才 `flatten_session`；`count > 1` 或 `wall_only` 时结果只 `_store(..., adopt_first=False)` 进图片墙；否则 `write_layer_image(...)` 写回目标层，`kind` 随目标是背景层还是普通图像层取 `BACKGROUND` / `GENERATED`。
- `expand_canvas_exec` / `upscale_image_exec`：`_store(..., adopt_first=not _layered(canvas))`——已拆层时拍平生成的整图带主体，不能自动采用。

### 2.2 `backend/app/services/sessions.py`

`switch_current` 增加 `document=await _last_document_for(session, record, asset.id)`。新增两个纯查询函数：

- `_document_for(state, asset_id)`：从一条历史 `state`（`result` 或 `params["before"]`）里取出属于该素材的文档 payload。
- `_last_document_for()`：按 `history_of()` 的倒序扫描，先查每步的 `result`，再查 `params["before"]`，命中即返回；都没命中则返回 `None`，`switch_current` 回退到按整图建文档。

## 3. 提交 3：图层×选区正交、按层拆步

### 3.1 入参基元 `backend/app/tools/base.py`

抽出共享模型，让「改哪一层」和「改哪块区域」成为可组合的正交字段：

- `LayerRef.layer_id`：带 `Field(description=...)`，明确「填 id 或名字，不填作用在选区下最上层可见图像」，因此对模型可见。
- `MaskRef`：`mask_asset_id` + `revision`，两者由服务端填。
- `HIDDEN_MASK = ("mask_asset_id", "revision")`：统一的 `agent_hidden` 常量。

### 3.2 目标解析 `backend/app/tools/target.py`

- `selection_mask()`：取选区，`EmptySelection → None`（是否改整层交调用方），`StaleSelection → ToolError(STALE_SELECTION)`。
- `require_selection()`：无选区即按传入文案报错（`promote_object` 用）。
- `resolve_target()`：包一层 `resolve_layer`，把 `LayerMissing` 转成可展示 `ToolError`。

`backend/app/layers.py` 的 `resolve_layer` 改为 id 命中优先、再按 `layer.name` 兜底（都先 `strip()`）。

### 3.3 区域工具 `backend/app/tools/region.py`（重写）

`RegionIn`/`ReplaceRegionIn` 改继承 `(LayerRef, MaskRef)`。拆出三个纯函数：

```python
def _target(document, layer_id, mask):
    if not layer_id and mask is not None:
        return layer_under_mask(document, mask)   # 没点名有选区→选区下最上层
    return resolve_target(document, layer_id)      # 点名→该层；都没→最上层图像

def _region(source, mask, layer, canvas):
    if mask is None:
        return alpha_mask(source)                  # 没选区→整层（用自身 alpha）
    try:
        return mask_for_layer(mask, layer, canvas) # 有选区→与该层交集
    except EmptyCut as exc:
        raise ToolError("选区没有覆盖到该图层") from exc
```

`_edit_region(session, run, *, scoped, whole)` 依 `mask is None` 选提示词（整层版 vs 选区版），`erase_region_exec` / `replace_region_exec` 各传两套文案。结尾 `selections.clear`。`agent_hidden=HIDDEN_MASK`，`layer_id` 因此暴露给模型。

### 3.4 其余工具

- `retouch.py`：`RemoveBackgroundIn`/`AdjustIn` 继承 `LayerRef`，执行改走 `resolve_target`，去掉 `agent_hidden=(_LAYER,)`（layer_id 对模型可见）。`ADJUST_IMAGE` 描述加「改成具体颜色或换材质要用 replace_region」。
- `canvas.py`：`LayerRef` 改从 `base` 导入；`ScaleIn` 增 `x`/`y`；`scale_layer` 把 `x/y` 透传进 `edits.document.scale`；`_canvas(..., hidden=())`，`SCALE_LAYER` 传 `_PLACEMENT=("x","y")` 隐藏位置参数，其余画布工具不再隐藏 `layer_id`。
- `layers.py`：`PromoteIn(MaskRef)`，`promote_object_exec` 改用 `require_selection`，`agent_hidden=HIDDEN_MASK`。

### 3.5 服务层与图 `backend/app/services`、`agent`

- `services/agent.describe()`：图层行改「`图层 N 个，自下而上（id=名字…）`」；选区行补「只限定区域，与 `layer_id` 同时给出取交集」，无选区时提示「区域工具会作用在整个图层」。`_layer_name` 前缀 `layer.id=`。
- `services/agent._pin_selection()` + `_wants_mask()`：`agent.run` 之后立即把当轮 `mask_asset_id` 钉进每个 `params` 里含 `mask_asset_id` 字段的步骤（已有则不覆盖），解决多步共用选区。
- `services/agent.continue_plan()`：去掉 `_advance` 前的 `await session.commit()`，同步的下一步与本次一起提交，前端不会捞到中间空档。
- `services/selections.mask_bytes()`：显式 id 优先；素材宽高 ≠ 画布宽高时 `raise StaleSelection`。
- `agent/graph.py` 系统提示词：新增「图层与选区是两个独立维度」「一句话改多个图层按图层拆多步」「改颜色/换材质用 replace_region 并点名 layer_id，adjust_image 只做明暗冷暖」「没有选区也能调用，作用在整个目标图层」，删掉旧的「不要操作名为原图的图层」。

### 3.6 编辑层 `backend/app/edits`

- `document.scale(..., x=None, y=None)`：把新位置与倍率写进同一次变更，供一条历史整体撤销。
- `mask.rasterize_strokes`：`len(points) > 2` 时先 `draw.polygon(points, fill=255)` 闭合填面积，再叠画描边轮廓兜底。

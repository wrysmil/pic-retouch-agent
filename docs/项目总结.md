## 一、项目定位

根据 [frontend/src/App.tsx](frontend/src/App.tsx) 中规划的路由（`/create` 创作、`/editor` 编辑、`/batch` 批量、`/candidates` 选出一张、`/marketing` 导出物料），以及后端依赖选型（rembg、onnxruntime、opencv、langgraph、langchain-openai），本项目是一个**面向电商/营销场景的图片修图 Agent**，核心能力包括：

- 单图创作与编辑（带 Konva 画布）
- 多候选出图筛选
- 批量修图
- 营销物料导出

工作流阶段按里程碑推进：`S3` 创作 → `S4` 编辑 → `S10` 导出物料 → `S11` 批量。

## 二、整体架构

**单体仓库（Monorepo），前后端同源部署**，由 [Dockerfile](Dockerfile) 多阶段构建完成。

```
pic-retouch-agent/
├── backend/          # FastAPI + Python 3.13
├── frontend/         # React 19 + Vite 8
├── docker-compose.yml
├── Dockerfile
├── .env.example
└── docs/             # 项目文档
```

最终交付物：单一镜像内含前端静态产物与后端服务，由 FastAPI 同源托管 7302 端口。

## 五、基础设施与部署

### 5.1 docker-compose 服务（[docker-compose.yml](docker-compose.yml)）

| 服务 | 镜像 | 端口 | 数据卷 | 备注 |
|---|---|---|---|---|
| postgres | postgres:17-alpine | 7311:5432 | pg_data | 用户/库 `retouch`，密码 `retouch_dev` |
| redis | redis:7-alpine | 7312:6379 | redis_data | — |
| minio | minio/minio:latest | 7313:9000（S3）/7314:9001（控制台） | minio_data | 凭证 `retouch/retouch_dev` |
| app（deploy profile） | 自建镜像 | 7302:7302 | cv_models（u2net） | uvicorn 启动 |
| worker（deploy profile） | 自建镜像 | — | cv_models | arq Worker |

- 三件套默认随 `docker compose up -d` 启动
- `app` 与 `worker` 放在 `profiles: ["deploy"]`，需 `docker compose --profile deploy up -d` 启动
- `cv_models` 卷用于在镜像间共享 U2Net 等 CV 模型

### 5.2 Dockerfile（[Dockerfile](Dockerfile)）

多阶段构建：

1. **阶段 1（前端构建）**：`node:22-alpine`，`npm ci` 后执行 `npm run build`，产物 `/build/dist`
2. **阶段 2（后端镜像）**：`python:3.13-slim`，通过 `uv`（来自 ghcr.io/astral-sh/uv）以 `uv sync --frozen --all-extras --no-dev` 安装依赖
3. **合并**：前端 `dist` 拷贝到 `/app/frontend/dist`，最终由后端同源托管
4. 暴露 `7302` 端口

### 5.3 环境变量（[.env.example](.env.example)）

需自行复制 `.env.example` 为 `.env` 用于部署配置（具体字段见 `.env.example`）。
